# freedom 7.30.0

发布日期：2026-10-12。适用于 Windows 10 2004 及以上版本、Windows 11，x64 架构。

## 更新检测修正

- 撤回 7.3.0，正式版本统一改为 **7.30.0**。
- 修正版本号顺序：7.30.0 高于 7.23.8，旧版更新器可以识别此次更新。
- 程序、共享库、更新器、安装包及 GitHub 发布标签均使用 7.30.0。
- 已安装 7.3.0 的用户也可以通过应用内更新升级。

## 节点与分流

- 修复配置项列表中，右键点击节点偶尔无法弹出菜单的问题，覆盖行内文字、空白和边缘区域。
- 右键操作准确对应点击的节点，保留已有多选，并完善滚动后和键盘调用时的菜单行为。
- 修复粘贴订阅链接后，节点已导入但订阅管理没有显示对应订阅的问题；管理列表显示订阅地址。
- 简化网站和应用分流规则，支持直连、阻断、指定节点以及跟随用户当前选择，支持订阅节点和本地节点。
- 优化 Hysteria2 分享链接解析、UDP Hop 与 FinalMask 配置生成，并在带宽设置中显示继承的全局上行、下行参数。
- 完善 UDP 接管、STUN 响应处理及隐私相关路由。

## 首页与网络诊断

- 精简侧栏和首页信息，移除左下角曲线及冗余文字。
- 优化流量曲线连续动画；窗口失去焦点但仍可见时继续平滑刷新，隐藏或最小化时暂停动画。
- 调整服务检测为紧凑卡片，支持地区、国旗、单项刷新、批量检测和取消。
- 改进服务检测证据解析，区分可访问、明确限制、登录要求、人机验证及临时服务错误，并显示具体原因。
- 完善 IP 详情，默认显示完整地址，提供地区、网络运营商、ASN 等信息及复制操作。

## 应用与内核更新

- 应用启动时检查更新；发现新版本时在应用内显示更新日志、下载及安装操作。
- 支持后台下载、SHA-256 校验、下载完成后在正常退出时安装，下次打开使用新版本。
- 更新检查保持安静，检查失败或发现更新时显示相应提示；右下角通知在 10 秒后自动收起。
- 设置新增自动更新内核选项；组件更新页面加入 freedom 本体更新。
- 完善内核更新包验证、替换与失败回滚。

## 安装说明

- 安装包：`freedom-windows-64-setup.exe`。
- 便携及应用内更新包：`freedom-windows-64.zip`。
- 两种包均附带 `.sha256` 校验文件，包含 .NET / WinUI 运行时及代理内核。
- 升级保留原有节点、订阅、设置和数据库，无需重新导入。
- 随包内核：Xray 26.9.30、sing-box 1.14.1、Mihomo 1.19.31。Xray 使用官方预发布版本，以支持本次已验证的 HY2 配置格式；官方归档的 SHA-256 已校验。
