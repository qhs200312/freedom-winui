# freedom 7.30.3 更新日志

构建日期：2026-10-26。适用于 Windows 10 2004 及以上版本、Windows 11，x64 架构。

## 安全修复

- 修复 Xray、sing-box 在允许局域网连接且使用原监听端口时，没有应用已设置用户名和密码的问题。共用端口和新端口两种模式均会启用已配置的认证，原监听地址和端口选择保持不变。
- 开启局域网共享但未填写完整用户名、密码时，在保存设置和生成配置时显示警告，覆盖现有 8 种界面语言。
- 为 Mihomo 的 external-controller 增加随机 secret，管理请求统一使用 Bearer 认证。secret 在每次启动应用时随机生成，会话内配置重载沿用，不写入日志。
- 在配置混合完成后设置控制器认证，防止源配置或 mixin 将其清空；同步处理生成的 sing-box 控制器认证。
- 调整进程启动参数处理，使用 ArgumentList 传递参数，避免含空格路径的手动引号拼接问题。

## 兼容性修复

- 为应用内部的连通性检测、出口 IP 查询、节点延迟测试、服务可用性检测和代理下载补齐本地代理认证。
- 修复共用端口启用认证后，旧式 TUN 保护的本地 SOCKS 转发缺少凭据的问题。
- 仅为指向本应用回环端口的系统代理配置本地认证，不向其他系统代理注入凭据。

## 首页模式切换

- 提供“规则分流”“全局代理”“直连模式”三个切换入口。
- 返回规则分流时优先恢复之前选择的有效规则方案。
- 直连模式将默认出口设为直连，已有自定义分流规则仍优先生效。

## 安装与升级

- 安装文件：`freedom-7.30.3-windows-x64-setup.exe`。
- 随包包含 .NET、Windows Desktop、WinUI 运行环境，以及代理核心和 UDP 接管依赖。
- 随包核心：Xray 26.9.30、sing-box 1.14.1、Mihomo 1.19.31、Nowhere 3.0.0。
- 沿用既有安装标识，覆盖升级时保留用户原有节点、订阅、设置和数据库。
- 新安装包不包含开发工作区中的运行配置、节点数据库或日志。
- 本次构建不表示已经清理旧工作区的凭据残留。此前已泄露的订阅 token 和节点密码仍需在服务商后台手动轮换。
