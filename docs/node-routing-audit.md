# 网站、应用和默认节点分流

检查日期：2026-10-10；2026-10-12 续检确认简化版发布文件与源代码时间一致，测试包完整性及补丁格式检查通过。实现范围：当前仓库的 WinUI 客户端、共享配置生成器以及 Xray / sing-box。

## 可用功能

路由规则集编辑界面的主要操作为“添加域名”“编辑”“删除”“默认节点”和“保存规则集”。规则集高级信息默认折叠；应用分流、导入、导出和新增高级规则放入更多菜单。

- 点击“添加域名”后只有“域名”和“处理方式”两个输入项；处理方式包含直连、阻断、当前选中节点及全部保存的节点。
- 直接填写 `example.com`，自动生成包含该域名及其子域名的规则。支持多行、逗号分隔、`*.example.com`、网站 URL 和国际化域名；无需填写核心规则前缀。无效或空域名不会保存，表单显示错误。
- 编辑已有简单网站规则使用同一表单，保留原来的启用状态。复杂的正则、关键字、IP、端口或应用规则继续使用高级表单，保留原来的匹配含义。
- 规则列表直接显示域名及出口。网站表单保存后，点击“保存规则集”提交到数据库。
- 应用使用进程名或可执行文件路径选择出口，支持通过文件选择器添加 `.exe`。
- 默认节点编辑器保存末尾的 `tcp,udp` 兜底规则。“当前选中节点”随主界面的节点选择变化，也可以固定一个保存的节点。
- 默认节点编辑器仅在保存时替换原有简单兜底规则；取消编辑不改变原规则。已有具体匹配规则继续生效。
- 应用 TCP / UDP 全面接管需要开启 TUN。普通 UDP 接管通过独立入站使用默认代理出口，不能按原应用分别选择节点。
- TUN 中应用进程匹配优先于通用 STUN 保护和普通网站规则；同一条规则附带的域名和 IP 部分仍保持原有网站规则顺序。DNS 接管、核心进程防环路等内建规则保留。

## 保存与兼容

新选择存入现有 `RulesItem.OutboundTag`，格式为 `node:<IndexId>`；无需修改数据库结构或重新导入节点。下拉框显示来源、节点名称、协议及短 ID，重名节点可分别选择。节点在原记录上改名不会改变绑定。

旧的 `proxy/direct/block` 规则以及按节点备注指定出口的旧规则仍可解析。新固定引用遇到节点删除、当前核心不支持或节点校验失败，会阻止生成配置并报告错误；旧备注规则保留原有警告及回退行为。

更新订阅会重建节点 ID，因此在订阅导入完成后迁移路由规则中的固定引用：

1. 优先比较现有的完整节点配置及名称。
2. 没有匹配时，允许完整节点配置唯一匹配，从而支持改名。
3. 仍没有匹配时，允许同订阅、同协议、旧新均唯一的名称匹配，从而支持服务商修改地址或凭据。
4. 多个候选或节点消失时不猜测出口，保留旧引用，运行配置校验时提示重新选择。

迁移覆盖网站、应用、默认以及禁用规则；本地节点引用和旧备注规则不变。节点名称和配置都改变时可能需要重新选择。自定义整份核心配置不作为可组合分流出口；不同节点必须能由运行核心处理，UDP 还需要节点自身支持转发。

启用 STUN 保护或普通 UDP 接管时，固定的默认代理节点也用于这些流量。默认设为直连或阻断时，STUN 保护仍保留当前代理出口。

## 主要实现文件

- `v2rayN/ServiceLib/Services/RoutingNodeSelection.cs`：节点列表、固定引用、默认代理和引用校验。
- `v2rayN/ServiceLib/Handler/Builder/CoreConfigContextBuilder.cs`：从数据库按 ID 或旧备注解析节点。
- `v2rayN/ServiceLib/Handler/ConfigHandler.cs`：订阅更新后的固定路由引用迁移。
- `v2rayN/ServiceLib/Services/CoreConfig/{V2ray,Singbox}`：生成相应出口、路由及应用优先级。
- `v2rayN/ServiceLib/ViewModels/RoutingRule{Setting,Details}ViewModel.cs`：网站、应用、默认编辑和取消行为。
- `v2rayN/v2rayN.WinUI/Views/RoutingRule{Editor,Details}View.cs`、`Services/WinUIPlatformService.cs`：入口、节点下拉框及程序选择器。
- `v2rayN/v2rayN.WinUI/MainWindow.xaml.cs`：让自定义规则集出现在主界面和托盘选择器。
- `v2rayN/ServiceLib.Tests/CoreConfig/RoutingNode{Selection,Runtime}Tests.cs`：新增回归及实际核心测试。

保留工作区原有 HY2 和 WebRTC 修改，没有重置用户节点、系统代理或正在运行的连接。
